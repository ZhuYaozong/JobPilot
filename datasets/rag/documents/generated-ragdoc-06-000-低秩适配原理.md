# 低秩适配原理

## 概念

低秩适配（Low-Rank Adaptation, LoRA）是一种高效的微调方法，旨在通过引入低秩矩阵来近似预训练模型权重更新的增量。其核心思想是冻结原始预训练权重，并在特定层（如注意力层的查询、键、值投影矩阵）旁路注入可训练的低秩分解矩阵。这种方式显著减少了可训练参数量，同时保持模型性能接近全参数微调。LoRA 特别适用于大语言模型（LLM）的领域适配任务，例如将通用模型定制为特定行业（如法律、医疗）的问答系统。由于参数量大幅降低，训练和存储成本也随之下降，且多个任务可以共享同一基座模型，仅需切换不同的 LoRA 权重。

## 原理

LoRA 的理论基础在于，预训练模型权重在微调过程中通常具有低的“内在维度”（intrinsic dimension），即权重更新量可以被低秩矩阵有效捕获。具体地，对于预训练权重矩阵 \(W_0 \in \mathbb{R}^{d \times k}\)，其更新量 \(\Delta W\) 被分解为两个低秩矩阵的乘积：\(\Delta W = BA\)，其中 \(B \in \mathbb{R}^{d \times r}\)，\(A \in \mathbb{R}^{r \times k}\)，且秩 \(r \ll \min(d, k)\)。在前向传播时，模型输出为 \(h = W_0 x + BA x\)。训练时仅更新 \(A\) 和 \(B\)，而 \(W_0\) 保持冻结。初始化时，通常将 \(A\) 采用随机高斯分布，\(B\) 初始化为零矩阵，从而保证训练从原始模型状态开始。缩放因子 \(\alpha / r\) 用于调整更新幅度，其中 \(\alpha\) 是一个常数超参数。通过合理设置秩 \(r\) 和 \(\alpha\)，可以平衡适配能力和过拟合风险。

## 实践案例

### 架构流程

以将通用 BERT 模型适配为金融情感分析任务为例，架构流程如下：

1. 加载预训练 BERT-base 模型，冻结所有原始参数。
2. 在 BERT 的每一层自注意力模块中，为 Q、K、V 和输出投影矩阵分别插入 LoRA 适配器（即低秩矩阵 \(A\) 和 \(B\)）。
3. 替换分类头为随机初始化的全连接层（该层不冻结）。
4. 设置训练循环：前向传播时计算原始输出和 LoRA 旁路输出之和，反向传播仅更新 LoRA 参数和分类头。
5. 训练完成后，将 LoRA 参数与原始权重合并（可选）以提升推理速度：\(W' = W_0 + \frac{\alpha}{r} BA\)。

### 关键参数

- **秩 \(r\)**：控制适配能力，常用值为 4、8、16。较小的 \(r\) 减少参数量但可能限制表达力。
- **缩放因子 \(\alpha\)**：建议设为与 \(r\) 相等的值（如 \(\alpha = 16\) 当 \(r=16\)），或根据学习率调整。
- **适配层选择**：通常只对注意力投影矩阵应用 LoRA，但也可扩展至 FFN 层。
- **学习率**：建议使用原模型微调学习率的 2-4 倍，如 5e-4。
- **优化器**：AdamW 或 SGD，权重衰减设为 0.01。

### 异常处理

- **训练损失不下降**：检查学习率是否过高或缩放因子 \(\alpha\) 设置不当；尝试减小 \(r\) 或增加 \(\alpha\)。
- **过拟合**：减少秩 \(r\) 或增大 Dropout 比例（如 0.1）。
- **梯度爆炸**：梯度裁剪设为 1.0，或降低学习率。
- **推理时合并权重错误**：确保缩放因子正确应用于 \(BA\)，且未与原始权重重复相加。

### 监控指标

- **参数量**：记录可训练参数占原模型比例（通常低于 1%）。
- **训练损失**：每个 epoch 的损失曲线。
- **验证集准确率/F1**：与全参数微调基线对比。
- **显存占用**：监控 GPU 显存峰值，LoRA 可降低显存需求约 30-50%。
- **推理延迟**：合并权重前后对比，合并后几乎无额外开销。

### 方案取舍

**优势**：
- 参数量极少，适合资源受限环境。
- 多任务部署时只需保存 LoRA 权重（数 MB），切换成本低。
- 避免灾难性遗忘，保持基座通用能力。

**劣势**：
- 对于需要大幅度调整权重的任务（如全新知识注入），性能可能不如全参数微调。
- 需要手动选择适配层和秩，存在一定调参开销。

**对比其他方法**：与 Adapter 类似但 LoRA 无额外推理延迟（合并后）；与 Prefix Tuning 相比，LoRA 更稳定且易实现。适用场景：领域适配、指令微调、个性化模型，不适合需要改变模型内部表示深度的任务。
