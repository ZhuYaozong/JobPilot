# LLM采样参数详解

## 概念
在大语言模型（LLM）的文本生成过程中，采样参数用于控制从模型输出的概率分布中选择下一个词的方式。这些参数直接影响生成内容的多样性、连贯性和确定性。常见的采样参数包括：temperature、top-p（核采样）、top-k、repetition_penalty等。Temperature调整概率分布的尖锐程度，低值使高概率词更突出，高值使分布更平坦。Top-p从累积概率超过阈值p的词汇中采样，动态选择候选集。Top-k固定选择概率最高的k个词。Repetition_penalty惩罚已出现过的词，减少重复。

## 原理
LLM在生成下一个词时，会输出一个logits向量（未归一化的分数），通过softmax函数转换为概率分布。采样参数作用于这一分布：
- Temperature：将logits除以温度T后再进行softmax，即softmax(logits/T)。T越小，高logits的概率相对更大，输出更确定；T越大，分布越均匀，输出更随机。典型范围0.1～2.0。
- Top-p：按概率从高到低排序，累积概率达到p时截断候选集，仅从这些词中重新归一化采样。p通常设为0.9～0.99。
- Top-k：直接保留概率最高的k个词（k常为10～100），重新归一化后采样。
- Repetition_penalty：对已出现过的词的logits施加惩罚（如乘以一个小于1的系数），降低其被再次选中的可能性，常用值1.1～1.3。
这些参数可组合使用（如先top-k再top-p），以达到期望的生成效果。

## 实践案例
假设使用OpenAI API风格生成新闻摘要，需控制风格为简洁且不重复。
### 架构流程
用户输入新闻正文 → 系统预处理（截断至2048 tokens） → 调用LLM接口（如GPT-4） → 应用采样参数生成输出 → 后处理（去除特殊字符） → 返回摘要。
### 关键参数
- temperature: 0.3（保持事实准确）
- top_p: 0.85（减少低频词干扰）
- max_tokens: 150
- repetition_penalty: 1.2（避免重复）
- frequency_penalty: 0.5（进一步降低常见词循环）
### 异常处理
- 输出为空：检查输入是否为空或过长，可降级为直接返回原文截断。
- 输出包含大量重复：提高repetition_penalty至1.5或降低temperature。
- 输出中断（未完成句子）：增加max_tokens或启用stop序列。
### 监控指标
- 响应时间（p95 < 2s）
- 生成多样性：distinct-1,2（图元/二元组比例）
- 重复率：连续n-gram重复比例，目标<5%
- 用户反馈准确率：人工抽查摘要是否包含核心事实
### 方案取舍
- 低temperature+高top-p：适合摘要、翻译等事实性任务，但可能过于保守。
- 高temperature+低top-k：适合创意写作，但容易偏离主题。
- 使用repetition_penalty会轻微增加计算开销（需记录已生成词），但能有效减少重复。
- 若需极低延迟（如实时对话），可选择纯top-k（k=40）以避免top-p的排序开销。
