# 多头注意力机制

## 概念
多头注意力（Multi-Head Attention）是Transformer模型的核心组件之一。它将输入序列的查询（Query）、键（Key）和值（Value）通过多个独立的注意力头并行计算，然后将所有头的输出拼接并线性变换得到最终结果。每个头关注输入的不同表示子空间，使模型能够同时捕捉不同位置和语义层面的依赖关系。多头注意力广泛用于自然语言处理、计算机视觉和多模态任务中。

## 原理
多头注意力的计算分为三步：线性变换、缩放点积注意力、拼接与投影。

1. 线性变换：输入X分别通过三组权重矩阵W_Q、W_K、W_V，得到Q、K、V。对于h个头，每个头有独立的权重，维度为d_model/h。
2. 缩放点积注意力：每个头计算注意力分数：Attention(Q_i, K_i, V_i) = softmax(Q_i K_i^T / √(d_k)) V_i，其中d_k为每个头的维度。
3. 拼接与投影：将所有头的输出拼接，再通过输出权重矩阵W_O映射回d_model维度。

公式：MultiHead(Q,K,V) = Concat(head_1,...,head_h) W_O，其中head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)。

## 实践案例
以机器翻译任务为例，实现一个8头注意力（h=8）的编码器层。

### 架构流程
1. 输入嵌入：源语言句子通过嵌入层得到d_model=512的向量。
2. 位置编码：添加正弦位置编码。
3. 多头注意力层：输入X经过LayerNorm后，计算8头自注意力。
4. 残差连接：注意力输出与输入相加。
5. 前馈网络：两层线性层（d_ff=2048）加ReLU激活。
6. 再次残差连接和LayerNorm，输出编码表示。

### 关键参数
- d_model：512
- h（头数）：8
- d_k = d_v = d_model / h = 64
- d_ff：2048
- Dropout：0.1
- 优化器：Adam，β1=0.9，β2=0.98，ε=1e-9
- 学习率：warmup后衰减，初始lr=2e-5

### 异常处理
- 显存溢出：若序列长度过长导致OOM，可采用梯度累积或降低batch size；或使用Flash Attention减少显存占用。
- NaN/Inf损失：在注意力分数计算中添加数值稳定措施（如将softmax的输入减去最大值）；检查学习率是否过大，必要时梯度裁剪（max_norm=1.0）。
- 收敛缓慢：检查是否使用了适当的初始化（如Xavier）；确保头数h能被d_model整除，否则部分维度未使用。

### 监控指标
- 训练损失：交叉熵损失，曲线应平滑下降。
- 注意力分布熵：监控各头注意力是否过于集中或分散，熵值过大或过小可能表示学习不正常。
- 梯度范数：避免梯度爆炸或消失。
- 验证集BLEU：翻译任务常用BLEU评估。
- 各头注意力权重可视化：检查是否学到合理的对齐模式。

### 方案取舍
- 头数选择：8头是经验值，更少头（如4）计算更快但可能丢失多样性；更多头（如16）可能带来收益但增加参数量和计算量。
- 共享注意力权重：跨层共享可减少参数，但可能牺牲性能。
- 相对位置编码：相比绝对位置编码，可处理更长的序列，但增加了复杂度。
- 稀疏注意力：对于超长序列可减少计算量，但实现复杂。
- 是否使用Pre-LN：先LayerNorm再注意力（Pre-LN）在训练时更稳定，但Post-LN在某些任务上表现更好。
