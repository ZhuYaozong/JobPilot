# 前馈网络与残差连接

## 概念

在Transformer架构中，前馈网络（Feed-Forward Network, FFN）是每个编码器和解码器层中紧随多头注意力机制的重要组件。FFN通常由两个线性变换和一个非线性激活函数组成，其作用是对每个位置的表示进行独立的非线性变换，增强模型的表达能力。残差连接（Residual Connection）则是一种跨层跳跃连接技术，将输入直接加到经过变换后的输出上，从而缓解深层网络中的梯度消失和退化问题。Transformer的每个子层（注意力层和FFN）都采用了“残差连接 + 层归一化”的标准设计，使得信息可以直通上层，便于梯度流动，同时允许模型学习恒等映射。

## 原理

前馈网络的结构：设输入为x，FFN首先通过线性变换W1将输入映射到高维隐藏空间，经激活函数（如ReLU或GELU）后，再通过线性变换W2映射回原始维度。公式为：FFN(x) = W2 * activation(W1 * x + b1) + b2。其中，隐藏层维度通常为模型维度的4倍（例如d_model=512, d_ff=2048）。这种先放大再缩小的设计使得每个位置拥有充分的参数容量来学习复杂特征。

残差连接的原理：对于子层函数F(x)（如注意力或FFN），输出为LayerNorm(x + F(x))。通过加法运算，输入x直接传递到下一层，梯度可以直接通过恒等分支回传，避免梯度消失。同时，残差结构允许网络跳过不必要的变换，当某层作用不大时，网络可以将其权重推向零，保留输入信息。在深层Transformer（如BERT-Large、GPT-3）中，残差连接是训练稳定性的关键。

## 实践案例

### 架构流程

假设实现一个6层编码器的Transformer模型，每层包含多头自注意力和FFN，均使用残差连接。以其中一层为例，流程如下：

1. 输入X进入多头自注意力层，计算注意力输出A。
2. 执行残差连接：X1 = LayerNorm(X + A)。
3. X1进入FFN，计算FFN输出F。
4. 执行残差连接：X2 = LayerNorm(X1 + F)。
5. X2作为下一层的输入。

FFN内部：先线性变换到d_ff维度（如2048），使用GELU激活，再线性变换回d_model（如512）。

### 关键参数

- `d_model`：模型维度，决定输入输出大小，常见值512、768、1024。
- `d_ff`：FFN隐藏层维度，通常为d_model的4倍，但也可设为其他倍数（如2.5倍或8倍）以调节计算量。
- `activation`：激活函数，常用ReLU、GELU或Swish。GELU在BERT中表现更优。
- `dropout`：FFN内部可加dropout（如0.1）防止过拟合，通常加在激活后或第二个线性层前。
- `layer_norm_eps`：层归一化的epsilon，默认1e-12。

### 异常处理

- **梯度爆炸**：若训练时损失出现NaN，可检查残差连接后的LayerNorm是否稳定，或降低学习率、增加梯度裁剪。
- **激活死区**：ReLU可能导致神经元死亡，使用GELU可缓解。若发现大量神经元输出恒为零，应切换激活函数。
- **残差连接失效**：若发现网络难以收敛，可移除LayerNorm的位置（Pre-LN vs Post-LN）。Pre-LN（先归一化再子层）更稳定。
- **显存溢出**：d_ff过大时导致显存不足，可减小d_ff或使用梯度检查点。

### 监控指标

- **训练损失与验证损失**：监控损失下降趋势，判断是否收敛。
- **梯度范数**：记录每层梯度L2范数，若过大（>10）则可能爆炸，需裁剪。
- **神经元激活率**：统计FFN中ReLU/GELU的激活比例，过低表示死区。
- **残差连接输出统计**：监测残差连接后输出的均值和方差，若方差过大则LayerNorm可能不稳定。
- **训练速度**：FFN参数量大（约d_model*d_ff*2），监控每步时间以评估计算瓶颈。

### 方案取舍

- **增大d_ff**：增加模型容量，但计算量和显存线性增长。适合任务复杂、数据量大时，否则易过拟合。
- **使用GELU代替ReLU**：训练更平滑，但计算稍慢。通常推荐GELU。
- **残差连接后LayerNorm的位置**：Post-LN（原始Transformer）需要warm-up，Pre-LN（如GPT）收敛更快且对学习率更鲁棒。推荐Pre-LN。
- **激活函数dropout**：在FFN中加dropout可正则化，但会降低有效容量。通常dropout设0.1-0.3之间。
- **FFN的层数**：部分变体（如Switch Transformer）使用多个FFN专家的混合，但标准Transformer单层FFN已足够。
