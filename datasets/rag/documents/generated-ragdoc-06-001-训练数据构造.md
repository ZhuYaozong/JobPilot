# LoRA/SFT 训练数据构造方法与最佳实践

## 概念

LoRA（Low-Rank Adaptation）是一种参数高效微调方法，通过在预训练模型权重矩阵上叠加低秩适配器，实现仅更新少量参数即可适应下游任务。SFT（Supervised Fine-Tuning）则是指使用标注数据对预训练模型进行全参数或部分参数的监督微调。训练数据构造是LoRA/SFT成功的关键，直接影响模型在目标任务上的表现。高质量的数据应具备多样性、平衡性、指令遵循准确性和低噪声。

## 原理

LoRA/SFT训练数据的核心目标是教会模型在给定指令下生成符合预期的输出。数据构造需要遵循以下原则：
1. **指令清晰性**：每条数据应包含明确的指令（instruction），以及对应的期望输出（output），必要时可加入输入（input）。
2. **多样性**：覆盖不同领域的任务、不同句式、不同长度，避免模型过拟合单一模式。
3. **平衡性**：各类别或难度的样本数量均衡，防止模型偏向高频模式。
4. **质量优先**：错误或模糊的标注会引入噪声，降低微调效果。数据构造流程通常包括：原始数据采集 → 清洗与过滤 → 格式化（如JSONL） → 质量检查 → 数据增强。

## 实践案例

### 架构流程
假设需要构造一个用于客服问答的LoRA训练数据集，流程如下：
1. **数据采集**：从历史客服日志中随机抽取10,000条对话，提取用户问题与客服标准答案。
2. **清洗与过滤**：去除包含敏感信息（如身份证号）的样本，通过正则表达式过滤非中文内容，删除长度小于5个字符或超过512个字符的样本。
3. **格式化**：每条数据统一为JSONL格式：{"instruction": "请回答以下客服问题", "input": "用户问题原文", "output": "标准答案"}。
4. **质量检查**：人工抽检5%样本，检查指令是否合理、输出是否准确、输入是否完整。抽检不合格率超过2%则返回前一步重新处理。
5. **数据增强**：对现有数据通过同义词替换、句式改写等方式扩充至20,000条，确保多样性。

### 关键参数
- **数据总量**：LoRA通常需要数千至数万条高质量样本，本案例设定为20,000条。
- **字段设计**：采用instruction-input-output三字段结构，input可为空。
- **格式**：JSONL，每行一个JSON对象，便于流式读取。
- **分割比例**：训练集90%，验证集10%。

### 异常处理
- **缺失值**：若output字段为空，删除该条数据。
- **重复样本**：通过MD5去重，保留第一出现。
- **噪声标注**：人工抽检发现错误时，记录错误类型并修正；连续发现10条以上错误则暂停流程，重新审视清洗规则。
- **超长样本**：截断至512个token，并记录日志以便后续分析。

### 监控指标
- **数据分布**：统计指令类型、输入长度、输出长度的分布，确保无长尾偏斜。
- **标签平衡**：按意图分类，计算各类别占比，最大类别与最小类别的比例不超过10:1。
- **质量分数**：人工抽检的准确率需达到98%以上。
- **去重率**：重复样本占比小于1%。

### 方案取舍
- **人工标注 vs. 自动化生成**：人工标注质量高但成本大，自动化生成速度快但可能引入噪声。本案例采用半自动化方式：自动化生成初版，再人工校验修正。
- **数据量**：LoRA在小数据量下即可收敛，过多数据反而增加训练时间和过拟合风险。本案例经实验确定20,000条为合适规模。
- **指令模板**：固定模板（如“请回答以下客服问题”）有助于模型学习任务格式，但可能限制泛化。权衡后采用固定与随机混合的指令前缀。
